# Real-Time Edge Detection using OpenCV

## Overview

This project implements a real-time edge detection system using Computer Vision and OpenCV. The application captures live video from a webcam, processes each frame, and highlights object boundaries using edge detection techniques.

The project demonstrates fundamental image processing concepts and serves as a beginner-friendly introduction to real-time computer vision applications.

---

## Features

- Live webcam video capture
- Real-time frame processing
- Edge detection using OpenCV
- Fast and lightweight implementation
- Easy to understand and modify
- Suitable for learning Computer Vision fundamentals

---

## Technologies Used

- Python
- OpenCV
- NumPy

---

## Project Workflow

1. Capture live video from webcam.
2. Convert frames to grayscale.
3. Apply image preprocessing (if required).
4. Perform edge detection.
5. Display original and processed frames in real time.
6. Exit application using a keyboard command.
